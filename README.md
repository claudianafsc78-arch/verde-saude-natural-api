# 🌿 Verde & Saúde Natural

O **Verde & Saúde Natural** é um projeto de desenvolvimento web criado para oferecer uma plataforma de produtos naturais. A aplicação permite visualizar o catálogo de produtos, adicionar produtos ao carrinho, realizar o pagamento e acompanhar o status do pedido.

O projeto foi desenvolvido com uma divisão entre **Front-End (UI)** e **Back-End (API)**, utilizando tecnologias web e Java com Spring Boot.

---

## 🎨 Projeto UI

A interface do projeto possui as seguintes telas:

1. Splash / Home
2. Login
3. Cadastro
4. Catálogo
5. Carrinho
6. Pagamento
7. Acompanhamento do pedido
8. Entregador / Minhas Entregas

### Tecnologias

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

---

## ⚙️ Projeto API — Back-End

### Tecnologias

* Java 21
* Spring Boot 4.0.8
* Spring Web
* Spring Data JPA
* H2 Database
* Maven
* Git
* GitHub

### 8 tarefas do projeto

1. **Tela de catálogo de produto**
2. **Tela de carrinho de compra**
3. **Cadastrar produtores**
4. **Processamento e tela de pagamento**
5. **Visualização de produtos e catálogo**
6. **Tela de acompanhamento de pedido**
7. **Adicionar produto ao carrinho**
8. **Efetuar pagamento de pedido**
